# Library

Консольное приложение на Java для учёта изданий и читателей библиотеки. Через меню в терминале можно выдавать и возвращать книги и журналы, искать и сортировать издания, смотреть статистику. Данные сохраняются в файлы и загружаются при следующем запуске.

Учебный проект, который я пишу, пока изучаю Java Core.

## Что умеет

- Добавлять книги и журналы, показывать список изданий, искать по названию или его части без учёта регистра.
- Регистрировать читателей (каждый получает номер билета) и удалять их, если у читателя на руках ничего нет.
- Выдавать и возвращать издания по номеру или по названию. Одному читателю можно выдать не больше трёх изданий. При выдаче по названию программа сама выбирает свободный экземпляр, а при возврате ищет издание среди тех, что числятся за читателем.
- Сортировать издания по номеру, по названию или так, чтобы свободные шли первыми.
- Показывать сводку по экземплярам: сколько копий каждого издания и какие из них свободны.
- Показывать статистику: сколько всего изданий и сколько выдано, разбивку по типам, самого активного читателя и читателей без изданий.
- Сохранять данные при выходе и загружать их при запуске.
- Работать дальше при некорректном вводе и повреждённых строках в файлах.

## Что использовано

- Java 25 и Maven
- ООП: абстрактный класс `LibraryItem` с наследниками `Book` и `Magazine`, полиморфные методы `toString`, `getLoanDays`, `convertToCSV`. Состояние издания меняется через `markIssued` и `markReturned`, сеттеров нет
- собственная иерархия исключений с общим родителем `LibraryException` и проверка данных в конструкторах
- коллекции `List`, `Map`, `LinkedHashMap`, `TreeMap`, `equals` и `hashCode` по неизменяемому `id`
- Stream API и лямбды: `filter`, `map`, `flatMap`, `groupingBy`, `Optional`, ссылки на методы, цепочки компараторов
- паттерн «Стратегия»: параметрами передаются способ сортировки (`getItemsSorted(Comparator)`), условие поиска (`findItems(Predicate)`), поиск издания по названию (`chooseItem(..., Function)`) и разбор строки файла (`loadFile(..., Consumer)`)
- работа с файлами через `java.nio.file`, формат CSV
- обобщённый метод для вывода списков любого типа

## Структура

```
src/main/java/
├── model/        LibraryItem, Book, Magazine, Reader
├── service/      Library: выдача, поиск, статистика
├── ui/           ConsoleMenu: меню и ввод
├── storage/      LibraryStorage: сохранение и загрузка
├── exceptions/   собственные исключения
├── testdata/     тестовые данные для первого запуска
└── Main.java     точка входа
```

`Library` не работает с консолью и файлами, `ConsoleMenu` не знает о файлах, `LibraryStorage` не знает о меню.

## Как запустить

Понадобятся JDK 25 или новее и Maven. Более старые версии Java проект не соберут: в конструкторах есть проверки до вызова `super(...)`, а это появилось только в Java 25.

Собрать и запустить из терминала:

```
git clone https://github.com/VladElizarov/library.git
cd library
mvn clean package
java -jar target/library-1.0.jar
```

Запускать `.jar` нужно из корня проекта. Программа ищет папку `data` относительно текущей папки терминала, поэтому при запуске из другого места она не найдёт сохранённые данные и начнёт с тестовых.

Можно обойтись и без терминала: открыть проект в IntelliJ IDEA и запустить `Main.java`.

При первом запуске загружаются тестовые данные. После выхода через пункт меню `0` появляется папка `data` с сохранёнными данными.

## Хранение данных

Данные лежат в папке `data` в трёх CSV-файлах:

| Файл | Содержимое | Пример строки |
|---|---|---|
| `items.csv` | издания | `Book;0;Война и мир;Лев Толстой;1300` |
| `readers.csv` | читатели | `1;Мария Сидорова` |
| `loans.csv` | выдачи (кто что взял) | `1;2` |

Отдельного поля «выдано» в файлах нет. Издание считается выданным, если оно есть в `loans.csv`, поэтому файлы не могут противоречить друг другу.

Повреждённую строку (не хватает полей, текст вместо числа, неизвестный тип) программа пропускает и выводит предупреждение с именем файла и номером строки:

```
Предупреждение: items.csv, строка 16: Поле количество страниц должно быть числом, получено: abc
```
